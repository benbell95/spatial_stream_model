    1. Core Workflow, Target & Data Source
    
              
    Select the pipeline entrypoint, variable(s), monitoring feed, and river network.
    
            
    
            Inputs
          
    
          
    
            
    
              
    
                
                
                  
                  Workflow Entrypointrun_s3n_determinand.R fits univariate S3N models + maps. run_s3n_cokriging.R fits multivariate Factor-LMC / Colocated co-kriging across 2+ targets. 01_preprocess_orn.py snaps stations onto ORN v2. Cards 5 & 6 also let you switch directly to 05_descriptive_stats.R, 04_compare_model_runs.R, and 06_station_snapping_diagnostics.R.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Target Code(s)Curated popular targets from the Usage Guide, grouped by Water Quality (15), Biology (inverts, diatoms, macrophytes), Habitat (rhs), and Co-Kriging suites. Select a specific --dataset to filter, or choose Custom... (use List Determinands above to inspect all available codes).
                
              
    
              
              
            
    

            
    
              
    
                
                
                  
                  Observation Modality (--dataset)Routes to the appropriate sample table: wq (water chemistry), inverts (WHPT), diatoms, macrophytes, rhs (River Habitat), or lcms (organic pollutants). Auto-detect infers the dataset automatically from target code.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Sample Network (--source)Combine networks with +. Options include statutory rsn (River Surveillance Network), ssn (Small Streams), rss (union), and custom/citizen feeds like waterblitz_tobit prepared with format_custom_data.py.
                
              
    
              
              
            
    

            
    
              
    
                
                
                  
                  Stream Topology (--network)orn selects England's Ordnance Survey Open Rivers Network v2 (90,876+ directed reaches). Switch to Custom... for a Bring-Your-Own-Water-Network (BYOWN) profile registered in configs/networks/.
                
              
    
              
              
            
    
          
    
        
    

        
        
    
          
    
            
    
              
    2. Transformations, Censoring & Spatial Model
    
              
    Control response scale normalization, detection limits, fixed effects, and kernels.
    
            
    
            Model Physics
          
    
          
    
            
    
              
    
                
                
                  
                  Normalization Scale (--transform)Defaults to log for WQ (ensures positivity on skewed concentrations) and none for ecology. Use boxcox for Profile-MLE optimal power λ, yeojohnson if data contain zeroes/negatives, or sqrt for moderate right skew.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Dimensionless Display Scale (--norm)Adds dimensionless comparison columns & maps while fitting in standard model units. robust_zscore ((x − median) / 1.4826·MAD) highlights local sub-catchment anomalies resistant to extreme outliers.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Non-Detect Handlingros uses Regression on Order Statistics; ros_site fits separate ROS curves per station (in 01_preprocess_orn.py); em activates iterative Spatial Tobit EM kriging (in run_s3n_determinand.R); half_lod uses 0.5 × detection limit.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Mean Structure / Joint EngineFor single-determinand runs: sets --trend=linear|gam|spline|rf|gbm (GAM/RF/GBM apply orthogonal out-of-fold spatial residual kriging). For Co-Kriging runs: switches --method=lmc (Factor-LMC Joint NNGP) vs. colocated.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Spatial Correlation Decay (--kernel)Shape of covariance decay along stream distance. auto evaluates Exponential, Spherical, Mariah, and Linear with sill kernels via Profile Likelihood and picks the best fit per domain.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Additive Function Value (--afv)Determines how Tail-Up variance splits at river confluences: equal upstream network length (length), Shreve stream order magnitude (shreve), or orographic rainfall + aquifer permeability proxy (hydro_yield).
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Tail-Up + Tail-Down Combination (--combine)joint (default) solves one unified TU+TD+Euclidean NNGP Cholesky system. precision uses legacy spatial information-gain averaging.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Custom Covariate Subset (--vars)Modify the default 6 predictors (elev,slope,urban,chalk,sand,clay) using modifiers like -chalk,-sand,+aquifer or an explicit list. Use List Covariates under Discovery for all columns.
                
              
    
              
              
            
    
          
    
        
    

        
        
    
          
    
            
    
              
    3. Validation, Threshold Risk, Time & Network Design
    
              
    Configure hydrological CV, exceedance mapping, dynamic time borrowing, and site placement.
    
            
    
            Decision Support
          
    
          
    
            
    
              
    
                
                
                  
                  Holdout Validation Strategy (--cv-mode)random uses 5-fold random splits; spatial uses K-means geographic blocks; catchment tests whole-basin extrapolation; downstream / upstream test flow-direction generalization.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  5-Tier Threshold Probability MappingComputes reach-level Gaussian exceedance probability P(Y > T) (or < T) using S3N mean & SE. uk auto-loads indicative thresholds (e.g. 11.3 mg/L Nitrate, 0.069 mg/L PO4, 6.0 mg/L DO, 5.0 WHPT).
                
              
    
              
              
    
                
                
              
    
            
    

            
    
              
    
                
                
                  
                  Spatio-Temporal Batching (--by)Slices data by season, year, or month with synchronized colorbars and fig6 trend slopes. Adding --st-borrow applies precision-weighted exponential smoothing across consecutive slices.
                
              
    
              
              
              
              
            
    

            
    
              
    
                
                
                  
                  Active-Learning Site Placement (--design-sites=K)Runs OpenMP C++ greedy Schur-complement selection (C_s3n_optimal_design) to rank top K unmonitored reaches maximizing variance reduction and renders fig_optimal_design_* maps.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Extra Basin Maps & Metrics (--basin)All England + Humber + Thames + Severn are always fitted. Pick a river name (e.g. Eden) or numeric CatchID (e.g. 3125) to render high-resolution dedicated basin figures (fig5+) and design rankings.
                
              
    
              
              
            
    

            
    
              
    
                
                
                  
                  Parametric Bootstrap Iterations (--boot)Controls bootstrap replicates for parameter confidence intervals (50 default). Set 0 for a fast run without bootstrap CIs, or 100 for tighter CIs.
                
              
    
              
            
    
          
    
        
    

        
        
    
          
    
            
    
              
    4. Multi-Source Fusion, Graphics & Compute
    
              
    Control statutory vs. citizen-science weighting, map DPI/format, and OpenMP threads.
    
            
    
            Fusion & Output
          
    
          
    
            
    
              
    
                
                
                  
                  Reach De-Duplication Priority (--prefer-source)When statutory (rsn, ssn) and citizen-science stations share the same reach, drops lower-priority observations on co-located reaches so statutory labs anchor those locations.
                
              
    
              
              
            
    

            
    
              
    
                
                
                  
                  Reliability Weighting (--source-weight)Applies analytic variance inflation V_wt = (1/w − 1)τ² per source (0 < w ≤ 1). Setting waterblitz:0.25 injects 3τ² extra measurement variance so citizen-science noise does not distort statutory fits.
                
              
    
              
              
            
    

            
    
              
    
                
                
                  
                  Known Analytical Noise Floor (--source-se)Injects explicit model-scale standard error (σ_source²) on top of nugget variance via the weighted C++ solver. Useful when test kits or sensors have calibrated lab error bars.
                
              
    
              
              
            
    

            
    
              
    
                
                
                  
                  Publication Graphics ModeUses PNG @ 200 DPI by default for fast rasterization; select PNG @ 300 DPI for crisp high-res national stream maps, SVG for resolution-independent vector diagnostics & small basins, or PDF for print typesetting.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Color Gradient PolarityStandard renders cool blue (low) → warm crimson (high), ideal for pollutants. --reverse-color flips the gradient so low ecological scores (like impaired WHPT ASPT or Dissolved Oxygen) glow warning red.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Parallel C++ Compute (--omp)Controls thread count inside s3n_fast_neighbors.so for NNGP likelihood, kriging prediction, weighted Co-Kriging, and Greedy Optimal Monitoring Design. Defaults to 1 in R; pass 4 on laptops or 8+ on workstations.

    7. Standalone Re-Plotting (03_generate_plots.R)
    
              
    Re-render publication maps, custom basins, or rescaled color bars from any saved model run without re-fitting.
    
            
    
            Graphics
          
    

          
    
            
            
            
          
    

          
    
            
    
              
    
                
                
                  
                  Model Output Directory (--dir)Folder containing saved predictions (e.g. output/results/det_0117_orn_rsn or a temporal batch folder).
                
              
    
              
              
            
    

            
    
              
    
                
                
                  
                  Basin Maps (--basin)Optional river name(s) or CatchID(s) to render high-resolution dedicated basin maps (e.g. Eden,Ribble).
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Fixed Lower Bound (--vmin)Optional lower limit for the map color bar (e.g. 0.2) to align scales across runs.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Fixed Upper Bound (--vmax)Optional upper limit for the map color bar (e.g. 20).
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Canvas Dimension Scaling (--fig-size)Scale output figure dimensions proportionally (e.g. 125%, +20%, or 80%).
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Normalised Map Mode (--norm)Re-render maps using saved normalised predictions (zscore, robust_zscore, percentile, or minmax).
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Color PolarityFlip gradient polarity with --reverse-color for ecological/oxygen metrics where low values indicate stress.
                
              
    
              
            
    

            
    
              
    
                
                
                  
                  Figure File Format & DPIExport raster PNG at 200 DPI (default) or 300 DPI, or resolution-independent vector SVG / PDF files.
