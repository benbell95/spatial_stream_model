The docs folder contains detailed instructions for using these scripts.

1. [Usage Guide](docs/usage_guide.md) - This provides usage instructions, lists all available commands and options.
2. [Preprocessing Pipeline](docs/preprocessing_pipeline.md) - This gives detailed technical information about the pre-processing stage (making the water network dataset compatible with this script).
3. [ORN Variables](docs/orn_variables_reference.md) - This provides detailed information about the variables available in the ORN water network dataset, and how these are used by the spatial model.
4. [Custom water network](docs/custom_water_network_guide.md) - This provides detailed technical information to use these scripts with different/custom water network datasets.
