# Open Rivers Network (`ORN_v2.gpkg`) Variables Reference for S3N Modelling

This document details all variables extracted from the **Ordnance Survey Open Rivers Network v2** ([`gis/ORN_v2.gpkg`](file:///home/ben/code/r/spatial_stream_model/gis/ORN_v2.gpkg)) during preprocessing ([`scripts/01_preprocess_orn.py`](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py)) and explains how each variable is used across the **Scalable Spatial Stream Network (S3N)** modelling, spatial covariance construction, and plotting stages.

## 1. Source Tables in `ORN_v2.gpkg`

[`scripts/01_preprocess_orn.py`](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L463-L669) queries five tables inside [`gis/ORN_v2.gpkg`](file:///home/ben/code/r/spatial_stream_model/gis/ORN_v2.gpkg):

| GeoPackage Table | Rows (National) | Role in [`01_preprocess_orn.py`](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py) |
| :--- | ---: | :--- |
| **`ORN`** | 183,322 reaches (90,876 in the 141 monitored catchments) | Primary river network layer providing reach geometry (`Shape`), topological nodes (`Fnode`, `Tnode`), catchment/basin identifiers (`CatchID`, `RBD_ID`), hydrologic distances (`Dist2Mth`, `US_Accum`), stream orders (`Shreve`, `Strahler`, `Hack`), and watercourse names (`name1`). |
| **`ORN_Sampled_100m`** | ~5,980,000 points | High-resolution 100 m sample points along reaches, aggregated via `GROUP BY PolylineID` ([lines 600–613](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L600-L613)) to obtain reach-level elevation, channel slope, sinuosity, source elevation, and BGS bedrock/superficial geology codes. |
| **`tblBedrockGeologyLookUp`** | Lookup table | Maps integer `LEX_RCS_BEDROCK` codes from `ORN_Sampled_100m` to British Geological Survey (BGS) bedrock lithology descriptions (`CHALK`, `LIMESTONE`, `DOLOSTONE`, `SANDSTONE`, etc.; [line 594](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L594)). |
| **`tblSuperficialGeologyLookUp`** | Lookup table | Maps integer `LEX_RCS_SUPERFICIAL` codes from `ORN_Sampled_100m` to BGS superficial deposit descriptions (`PEAT`, etc.; [line 595](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L595)). |
| **`tblRiverBasinLookUp`** | 11 River Basin Districts | Maps `RBD_ID` to Environment Agency River Basin District names (`Humber`, `Thames`, `Severn`, `Anglian`, `North West`, etc.; [line 596](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L596)). |

## 2. Spatial Stream Network Topology & Covariance Variables

These variables are passed to the compiled C++/OpenMP neighbor engine ([`src/s3n_fast_neighbors.cpp`](file:///home/ben/code/r/spatial_stream_model/src/s3n_fast_neighbors.cpp)) to construct the directed river tree, test flow-connectedness, compute pairwise hydrologic stream distances, and evaluate Tail-Up and Tail-Down spatial covariance weights:

| Exported Variable | Source Column(s) in `ORN_v2.gpkg` | Derivation in [`01_preprocess_orn.py`](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py) | Role in S3N Modelling ([`s3n_fast_neighbors.cpp`](file:///home/ben/code/r/spatial_stream_model/src/s3n_fast_neighbors.cpp), [`run_s3n_determinand.R`](file:///home/ben/code/r/spatial_stream_model/scripts/run_s3n_determinand.R)) |
| :--- | :--- | :--- | :--- |
| **`RivID`** | `ORN.RivID` (`ORN_Sampled_100m.PolylineID`) | Unique integer identifier for each river reach. | Primary key linking snapped RSN monitoring stations ([`rsn_sites.csv`](file:///home/ben/code/r/spatial_stream_model/data/processed/rsn_sites.csv)) to stream reaches and indexing parent–child links. |
| **`CatchID`** | `ORN.CatchID` | Unique integer identifier for each independent river catchment draining to a sea/estuary mouth. | Defines connected river trees (`net_id[a] == net_id[b]` in [`C_compute_s3n_neighbors()`](file:///home/ben/code/r/spatial_stream_model/src/s3n_fast_neighbors.cpp#L106)); reaches in different `CatchID` trees have zero spatial covariance (`fc = false, wt = 0.0`). Also used to order reaches by catchment and filter individual basins (e.g. Humber `CatchID=80`, Thames `CatchID=3055`, Severn `CatchID=2786`). |
| **`parent_dn`** | `ORN.Fnode`, `ORN.Tnode`, `ORN.CatchID` | Matches each reach's downstream node `(CatchID, Tnode)` to the upstream node `(CatchID, Fnode)` of its immediate downstream reach ([lines 673–698](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L673-L698)); set to `0` (`-1` in 0-based C indexing) for river mouth roots. | Used by [`C_build_tree_tin_tout()`](file:///home/ben/code/r/spatial_stream_model/src/s3n_fast_neighbors.cpp#L27-L70) to compute Euler-tour DFS entry/exit timestamps (`tin`, `tout`) for $O(1)$ flow-connectedness checks (`tin[a] <= tin[b] && tout[b] <= tout[a]`), and walked downstream to locate the Lowest Common Ancestor (LCA) confluence `anc` for flow-unconnected tributaries ([lines 119–123](file:///home/ben/code/r/spatial_stream_model/src/s3n_fast_neighbors.cpp#L119-L123)). |
| **`Dist2Mth_km`** | `ORN.Dist2Mth` | Hydrologic distance (converted from m to km) from the reach's upstream node (`Fnode`) to the sea/estuary river mouth ([line 741](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L741)). | Provides the exact distance to the mouth (`ncj_up = d2m_km[anc]`) at the confluence junction `anc` where two bifurcated tributaries meet, enabling exact across-confluence stream distance calculation: $d_{\text{stream}}(a,b) = d_{\text{up}}(a) + d_{\text{up}}(b) - 2\,\text{Dist2Mth\_km}(\text{anc})$ ([line 124](file:///home/ben/code/r/spatial_stream_model/src/s3n_fast_neighbors.cpp#L124)). |
| **`obs_up_dist_km`** | `ORN.Dist2Mth`, `ORN.Shape` | Exact hydrologic distance (km) from a snapped monitoring station to the river mouth: $\max(0, (\text{Dist2Mth} - s_{\text{along}})/1000)$, where $s_{\text{along}}$ is the distance from the upstream `Fnode` to the station's orthogonal projection along the reach polyline ([lines 526, 751](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L526)). | 1. Orders observed reaches downstream-to-upstream (`order(df$CatchID, df$obs_up_dist_km)`) for the Vecchia NNGP conditioning sets ([`run_s3n_determinand.R` L444](file:///home/ben/code/r/spatial_stream_model/scripts/run_s3n_determinand.R#L444)).<br>2. Provides `up_dist` for observed reaches (`has_obs == 1`) when computing pairwise hydrologic distances $|d_{\text{up}}(a) - d_{\text{up}}(b)|$. |
| **`up_dist_mid_km`** | `ORN.Dist2Mth`, `ORN.Shape` | Hydrologic distance (km) from the geometric midpoint of the reach to the river mouth: $\max(0, \text{Dist2Mth\_km} - 0.5 \times \text{length\_km})$ ([line 743](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L743)). | Provides `up_dist` for unobserved prediction reaches (`has_obs == 0`) when computing stream distances between prediction reaches and their $m = 15$ nearest observed neighbors ([`run_s3n_determinand.R` L452](file:///home/ben/code/r/spatial_stream_model/scripts/run_s3n_determinand.R#L452)). |
| **`log_AFV`** | `ORN.US_Accum`, `ORN.Fnode`, `ORN.Tnode` | Natural logarithm of the **Additive Function Value (AFV)** ([lines 684–698](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L684-L698)). Initialized at $\log\text{AFV}(\text{mouth}) = 0$ and accumulated upstream at every confluence in proportion to each tributary's upstream accumulated network length $A_p = \max(10^{-4}, \text{US\_Accum}_p)$:<br>$$\log\text{AFV}(p) = \log\text{AFV}(u) + \log\!\left(\frac{A_p}{\sum_{q \in \text{parents}(u)} A_q}\right)$$ | Used in the **S3N Tail-Up (`model_type = 0`)** covariance kernel ([`s3n_fast_neighbors.cpp` L114–L116](file:///home/ben/code/r/spatial_stream_model/src/s3n_fast_neighbors.cpp#L114-L116)) to compute Ver Hoef & Peterson (2010) flow-connected confluence weights:<br>$$\text{wt}(a,b) = \sqrt{\frac{\text{AFV}_{\text{up}}}{\text{AFV}_{\text{dn}}}} = \exp\!\Big(\tfrac{1}{2}\big(\min(\log\text{AFV}_a, \log\text{AFV}_b) - \max(\log\text{AFV}_a, \log\text{AFV}_b)\big)\Big)$$ |

## 3. Fixed-Effect Regression Covariates ($\mathbf{X}$)

These variables are assembled into the standardized design matrix $\mathbf{X}$ by [`build_design_matrix()`](file:///home/ben/code/r/spatial_stream_model/scripts/run_s3n_determinand.R#L396-L433) (in both [`scripts/run_s3n_determinand.R`](file:///home/ben/code/r/spatial_stream_model/scripts/run_s3n_determinand.R#L396-L433) and [`scripts/02_fit_s3n_models.R`](file:///home/ben/code/r/spatial_stream_model/scripts/02_fit_s3n_models.R#L41-L78)) and used as predictors in Non-Spatial OLS, `BRISC_estimation_stream`, and `BRISC_prediction_stream`:

| Predictor in Design Matrix $\mathbf{X}$ | Exported Column in [`england_rsn_reaches.csv`](file:///home/ben/code/r/spatial_stream_model/data/processed/england_rsn_reaches.csv) | Source in `ORN_v2.gpkg` | Derivation & Transformation |
| :--- | :--- | :--- | :--- |
| **`Elevation_z`** | `Elevation` | `ORN_Sampled_100m.OS_T50_Ele` | Mean OS Terrain 50 elevation (m above ordnance datum) across 100 m sample points on the reach (`AVG(OS_T50_Ele)`), $z$-score standardized (`scale(df$Elevation)`). Also used in Figure 4D to classify **Upland ($\ge 150\text{ m}$)** vs. **Lowland ($< 150\text{ m}$)** reaches. |
| **`Slope_z`** | `Slope` | `ORN_Sampled_100m.Slope` | Mean channel gradient (%) along the reach (`AVG(Slope)`), $z$-score standardized (`scale(df$Slope)`). |
| **`log10_US_Accum_z`** | `US_Accum_km` | `ORN.US_Accum` | Total upstream accumulated channel length (converted from m to km), transformed via $\log_{10}(\max(10^{-4}, \text{US\_Accum\_km}))$ and $z$-score standardized as a proxy for catchment drainage area and river discharge. |
| **`Is_Chalk_Limestone`** *(All England model)* | `Is_Chalk_Limestone` | `ORN_Sampled_100m.LEX_RCS_BEDROCK` + `tblBedrockGeologyLookUp` | Binary indicator (`1` or `0`) equal to `1` if the reach's dominant BGS bedrock description contains `CHALK`, `LIMESTONE`, or `DOLOSTONE` ([line 736](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L736)). Captures carbonate/chalk groundwater baseflow enrichment. |
| **`Is_Sandstone`** *(All England model)* | `Is_Sandstone` | `ORN_Sampled_100m.LEX_RCS_BEDROCK` + `tblBedrockGeologyLookUp` | Binary indicator (`1` or `0`) equal to `1` if the reach's dominant BGS bedrock description contains `SANDSTONE` and does not contain `MUDSTONE` or `SILTSTONE` ([line 737](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L737)). Captures Permo-Triassic and other principal sandstone aquifers. |
| **`Is_Peat`** *(All England model)* | `Is_Peat` | `ORN_Sampled_100m.LEX_RCS_SUPERFICIAL` + `tblSuperficialGeologyLookUp` | Binary indicator (`1` or `0`) equal to `1` if the reach's dominant BGS superficial deposit description contains `PEAT` ([line 739](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L739)). Captures upland blanket bog / organic soil regimes. |
| **`Is_Aquifer`** *(Regional/single-basin models)* | `Is_Aquifer` | Derived from `Is_Chalk_Limestone` and `Is_Sandstone` | Composite binary indicator (`1` if `Is_Chalk_Limestone == 1` or `Is_Sandstone == 1`, else `0`; [line 738](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L738)). Used in regional/single-basin fits (`include_peat = FALSE`) where individual geological classes may have zero variance, and in Figure 4D to stratify **Lowland Non-Aquifer** vs. **Lowland Aquifer** reaches. |
| **`Easting_z`**, **`Northing_z`** | `mid_X`, `mid_Y` | `ORN.Shape` (WKB `LineString` / `MultiLineString`) | British National Grid (`EPSG:27700`) coordinates (m) interpolated at the exact half-length ($0.5 L$) of the reach polyline ([lines 645–655](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L645-L655)), $z$-score standardized (`scale(df$mid_X)`, `scale(df$mid_Y)`) to capture large-scale climatic and agricultural gradients. Also used as Euclidean tie-breaker distances (`1e6 + d_eucl`) when padding zero-weight neighbors across separate catchments ([`s3n_fast_neighbors.cpp` L136–L138](file:///home/ben/code/r/spatial_stream_model/src/s3n_fast_neighbors.cpp#L136-L138)). |

> [!NOTE]
> **Automatic Collinearity / Zero-Variance Guard:** In [`scripts/run_s3n_determinand.R` (line 431)](file:///home/ben/code/r/spatial_stream_model/scripts/run_s3n_determinand.R#L431), [`build_design_matrix()`](file:///home/ben/code/r/spatial_stream_model/scripts/run_s3n_determinand.R#L396-L433) automatically checks `apply(X[df$has_obs == 1, -1, drop = FALSE], 2, sd) > 0` and drops any indicator column that is constant across the observed reaches of a sub-basin.
>
> **Short-Reach Covariate Imputation:** For short reaches ($< 100\text{ m}$) that did not contain a point in `ORN_Sampled_100m`, [`01_preprocess_orn.py` (lines 701–713)](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L701-L713) runs 3 forward/backward passes along the river tree (`topo_order`) to inherit `Elevation`, `Slope`, `Sinuosity`, `SrcElevation`, and geology codes from immediate downstream/upstream connected reaches, leaving 0 missing values across all 90,876 reaches.

## 4. Variables Extracted for Visualization, Basin Selection & Reference Only

The remaining ORN variables exported by [`scripts/01_preprocess_orn.py`](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py) do not enter the S3N regression or covariance equations directly, but are used for map rendering, custom `--basin` filtering, or auxiliary reference:

| Exported Variable | Source in `ORN_v2.gpkg` | Where Used |
| :--- | :--- | :--- |
| **`start_X`, `start_Y`, `end_X`, `end_Y`** | `ORN.Shape` (`poly[0]`, `poly[-1]`) | Upstream (`Fnode`) and downstream (`Tnode`) reach endpoint coordinates in `EPSG:27700` (m). Used by [`plot_stream_network()`](file:///home/ben/code/r/spatial_stream_model/scripts/s3n_plot_functions.R#L28-L83) in [`scripts/s3n_plot_functions.R`](file:///home/ben/code/r/spatial_stream_model/scripts/s3n_plot_functions.R) to draw the two half-segments `(start_X, start_Y) -> (mid_X, mid_Y)` and `(mid_X, mid_Y) -> (end_X, end_Y)` for every reach. |
| **`Shreve`** | `ORN.Shreve` | Shreve stream magnitude (number of upstream headwater sources). Used in [`plot_stream_network()`](file:///home/ben/code/r/spatial_stream_model/scripts/s3n_plot_functions.R#L37-L44) to scale plotted river line widths (`lwd = pmin(max_lwd, base_lwd + scale_lwd * log10(pmax(1, df$Shreve)))`) and in [`01_preprocess_orn.py` (line 633)](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L633) to identify the mainstem river name (`Main_River`) for each catchment. |
| **`Strahler`** | `ORN.Strahler` | Strahler stream order ($1 \dots 7$). Exported to [`england_rsn_reaches.csv`](file:///home/ben/code/r/spatial_stream_model/data/processed/england_rsn_reaches.csv) and prediction CSVs as a standard hydromorphological attribute. |
| **`RBD_ID`** & **`RBD_Name`** | `ORN.RBD_ID` + `tblRiverBasinLookUp` | Environment Agency River Basin District identifier and name. Exported to [`england_rsn_reaches.csv`](file:///home/ben/code/r/spatial_stream_model/data/processed/england_rsn_reaches.csv) and [`rsn_catchments_lookup.csv`](file:///home/ben/code/r/spatial_stream_model/data/processed/rsn_catchments_lookup.csv); used by [`resolve_basin_spec()`](file:///home/ben/code/r/spatial_stream_model/scripts/run_s3n_determinand.R#L649-L716) when running `--basin=<RBD_Name>` or `--basin=rbd:<RBD_ID>`. |

Saved as `Main_River` in [`rsn_catchments_lookup.csv`](file:///home/ben/code/r/spatial_stream_model/data/processed/rsn_catchments_lookup.csv) to support `--basin=<RiverName>` (e.g. `--basin=Eden`, `--basin="Great Ouse"`). |
| **`length_km`** | `ORN.Shape` | Euclidean polyline length of the reach (km), computed by summing vertex segment lengths ([lines 638–644](file:///home/ben/code/r/spatial_stream_model/scripts/01_preprocess_orn.py#L638-L644)). Used during preprocessing to interpolate `(mid_X, mid_Y)` and `up_dist_mid_km`. |
